# Документация к скрипту run_finetune.py

## Общее описание
Скрипт `run_finetune.py` - это Python-версия оригинального bash-скрипта `run_finetune.sh`, 
предназначенная для запуска процесса дообучения (fine-tuning) модели YuE с использованием 
метода Low-Rank Adaptation (LoRA). Скрипт запускает дообучение модели на пользовательских
данных с использованием оптимизации DeepSpeed для эффективного распределенного обучения.

## Требования
- Python 3.11+
- PyTorch с поддержкой CUDA
- DeepSpeed
- Предобработанные данные в формате Megatron
- Достаточное количество GPU для дообучения модели

## Параметры конфигурации
Скрипт использует следующие параметры, которые настраиваются внутри кода:

### Параметры оборудования:
- `NUM_GPUS`: Количество GPU для использования (по умолчанию 8)
- `MASTER_PORT`: Порт для распределенного обучения (по умолчанию 9999)
- `CUDA_VISIBLE_DEVICES`: Можно установить для выбора конкретных GPU

### Гиперпараметры обучения:
- `PER_DEVICE_TRAIN_BATCH_SIZE`: Размер батча на одном GPU для обучения (по умолчанию 1)
- `PER_DEVICE_EVAL_BATCH_SIZE`: Размер батча на одном GPU для валидации (по умолчанию 1)
- `USE_BF16`: Использовать ли формат BFloat16 (по умолчанию True)
- `SEQ_LENGTH`: Максимальная длина последовательности (по умолчанию 8192)
- `TRAIN_ITERS`: Количество итераций обучения (по умолчанию 150)
- `NUM_TRAIN_EPOCHS`: Количество эпох обучения (по умолчанию 10)

### Пути к данным:
- `DATA_PATH`: Путь к данным в формате "weight1 path1 weight2 path2..."
- `DATA_CACHE_PATH`: Путь к кэшу данных
- `DATA_SPLIT`: Пропорции разделения данных (по умолчанию "900,50,50")

### Конфигурация модели:
- `TOKENIZER_MODEL_PATH`: Путь к модели токенизатора
- `MODEL_NAME`: Имя или путь к базовой модели (по умолчанию "m-a-p/YuE-s1-7B-anneal-en-cot")
- `MODEL_CACHE_DIR`: Директория для кэширования модели
- `OUTPUT_DIR`: Директория для сохранения результатов
- `DEEPSPEED_CONFIG`: Путь к конфигурации DeepSpeed (по умолчанию "config/ds_config_zero2.json")

### Конфигурация LoRA:
- `LORA_R`: Ранг LoRA-матриц (по умолчанию 64)
- `LORA_ALPHA`: Масштабный коэффициент LoRA (по умолчанию 32)
- `LORA_DROPOUT`: Вероятность dropout для LoRA (по умолчанию 0.1)
- `LORA_TARGET_MODULES`: Целевые модули для применения LoRA (по умолчанию "q_proj k_proj v_proj o_proj")

### Параметры логирования:
- `LOGGING_STEPS`: Частота шагов для логирования (по умолчанию 5)
- `SAVE_STEPS`: Частота шагов для сохранения чекпоинтов (по умолчанию 5)
- `USE_WANDB`: Использовать ли Weights & Biases для логирования (по умолчанию True)
- `WANDB_API_KEY`: API-ключ для Weights & Biases
- `RUN_NAME`: Имя для запуска в WandB (по умолчанию "YuE-ft-lora")

## Использование
```
python scripts/run_finetune.py [--help]
```

### Опции
- `--help`, `-h`: Показать справочную информацию

## Перед запуском
Перед запуском скрипта необходимо:

1. Обновить параметры конфигурации в скрипте, заменив все заполнители (<...>) фактическими значениями
2. Убедиться, что входные данные уже преобразованы в формат Megatron (с помощью `preprocess_data.py`)
3. Убедиться в наличии доступа к достаточному количеству GPU с поддержкой CUDA

## Процесс выполнения
Скрипт выполняет следующие шаги:

1. Проверяет наличие всех необходимых параметров и директорий
2. Настраивает переменные окружения
3. Формирует команду для запуска процесса дообучения с torchrun
4. Запускает команду и отображает её вывод в реальном времени
5. Проверяет результат выполнения и выводит соответствующее сообщение

## Пример использования
```bash
# Перед запуском отредактируйте скрипт, заменив заполнители на фактические значения
python scripts/run_finetune.py
```

## Зависимость от других файлов
- `scripts/train_lora.py`: Основной скрипт Python для обучения с LoRA
- `config/ds_config_zero2.json`: Конфигурация DeepSpeed для Zero-2 оптимизации

## Выходные данные
После успешного завершения скрипта, дообученная модель будет сохранена в указанной директории OUTPUT_DIR.
Если включено логирование WandB, то прогресс и метрики обучения будут доступны в интерфейсе Weights & Biases.
