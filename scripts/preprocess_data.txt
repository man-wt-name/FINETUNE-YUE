# Документация к скрипту preprocess_data.py

## Общее описание
Скрипт `preprocess_data.py` используется для предварительной обработки аудио и текстовых данных для обучения модели YuE. 
Он преобразует исходные данные в формат, подходящий для обучения мультимодальной модели, 
создавая бинарные файлы в формате Megatron, которые затем можно использовать для дообучения модели.

## Требования
- Python 3.11+
- Доступ к модулю core/preprocess_data_conditional_xcodec_segment.py
- Структурированные данные в формате JSONL

## Использование
```
python preprocess_data.py <setting> <mode_type> <tokenizer_model> [--audio-prompt-modes MODES]
```

### Обязательные аргументы
- `setting`: Настройка данных (например, "dummy")
- `mode_type`: Тип режима обработки ("cot" или "icl_cot")
- `tokenizer_model`: Путь к модели токенизатора

### Дополнительные аргументы
- `--audio-prompt-modes`: Список режимов аудио-промптов для icl_cot (по умолчанию: dual, inst, vocal, mixture)

## Режимы обработки

### Режим "cot" (Chain-of-Thought)
Режим "цепочка мыслей" создает данные для дообучения, где текст и аудио чередуются на уровне токенов. 
Этот режим используется для тренировки модели на пошаговую генерацию аудио на основе текста.

### Режим "icl_cot" (In-Context Learning + Chain-of-Thought)
Режим "обучение в контексте + цепочка мыслей" создает данные для дообучения с использованием
аудио-промптов. Модель учится использовать имеющиеся примеры для улучшения генерации.
Имеет несколько подрежимов аудио-промптов:
- `dual`: Использует и вокал, и инструментал как промпты
- `inst`: Использует только инструментальную дорожку как промпт
- `vocal`: Использует только вокальную дорожку как промпт
- `mixture`: Использует смешанное аудио как промпт

## Функции скрипта

### run_command(cmd)
Запускает внешнюю команду и выводит результаты выполнения в реальном времени.
- `cmd`: Список аргументов команды

### remove_files(pattern)
Удаляет файлы по заданному шаблону, игнорируя ошибки, если файлы не существуют.
- `pattern`: Шаблон имён файлов для удаления

### preprocess_cot_mode(...)
Обрабатывает данные в режиме Chain-of-Thought.
- Параметры:
  - `data_root`: Корневой каталог данных
  - `name_prefix`: Префикс имени файла данных
  - `tokenizer_model`: Путь к модели токенизатора
  - `codec_type`: Тип кодека (обычно "xcodec")
  - `instruction`: Инструкция для модели
  - `order`: Порядок следования текста и аудио (textfirst/audiofirst)
  - `dropout`: Вероятность исключения инструкции
  - `quantizer_begin_idx`: Начальный индекс квантизатора
  - `num_quantizers`: Количество квантизаторов
  - `keep_sequential_samples`: Флаг для сохранения последовательных примеров

### preprocess_icl_cot_mode(...)
Обрабатывает данные в режиме In-Context Learning + Chain-of-Thought.
- Параметры те же, что и для preprocess_cot_mode, плюс:
  - `audio_prompt_modes`: Список режимов аудио-промптов

## Примеры использования

### Для режима "cot"
```bash
python preprocess_data.py dummy cot ./mm_tokenizer_v0.2_hf/tokenizer.model
```

### Для режима "icl_cot" с указанием конкретных режимов аудио-промптов
```bash
python preprocess_data.py dummy icl_cot ./mm_tokenizer_v0.2_hf/tokenizer.model --audio-prompt-modes dual vocal
```

## Результаты
Скрипт создаёт бинарные файлы данных в формате Megatron в подкаталоге `mmap` указанного 
каталога данных. Эти файлы можно затем использовать для обучения модели YuE.
